# Dr. Gayathri Periyasami - Professional Portfolio Website

A modern, responsive portfolio website for Dr. Gayathri Periyasami, MBBS, MS (OG), DNB - Consultant in Obstetrics & Gynaecology at KMCH Specialty Hospital, Erode.

## 🌟 Overview

This professional healthcare portfolio showcases Dr. Gayathri's expertise, experience, and services in women's healthcare. The website features a clean, modern design with interactive elements and comprehensive contact information for patients and colleagues.

## ✨ Features

### 🎨 Design & User Experience
- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with elegant typography using Playfair Display and Poppins fonts
- **Interactive Navigation**: Smooth hamburger menu for mobile devices with animated transitions
- **Image Carousel**: Auto-rotating carousel showcasing medical achievements and patient care highlights

### 📱 Interactive Components
- **Contact Form**: Integrated Google Forms submission with real-time character counting
- **Social Media Integration**: Direct links to Instagram, WhatsApp, Gmail, and phone contact
- **Location Integration**: Embedded Google Maps for easy hospital location access
- **Mobile-Optimized**: Touch-friendly interface with optimized mobile navigation

### 🏥 Content Sections
- **Professional Profile**: Detailed biography highlighting education, experience, and specializations
- **Experience Showcase**: Cards highlighting 10+ years of expertise in Obstetrics & Gynaecology
- **Hospital Information**: Details about KMCH Specialty Hospital location and facilities
- **Patient Testimonials**: Visual carousel with patient care stories and medical achievements
- **Contact Information**: Multiple contact methods with direct action links

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Node.js (for development) - Optional
- Text editor or IDE (VS Code recommended)

### Installation

1. **Clone or Download the Repository**
   ```bash
   git clone https://github.com/shankar4112/Doctor_Portfolio.git
   cd Doctor_Portfolio
   ```

2. **Install Development Dependencies** (Optional)
   ```bash
   npm install
   ```

3. **Open the Website**
   - Simply open `index.html` in your web browser
   - Or use a local development server for better experience

### Development Setup

If you want to modify the styling or add TailwindCSS features:

```bash
# Install dependencies
npm install

# Build CSS (if using TailwindCSS build process)
npx tailwindcss -i ./input.css -o ./style.css --watch
```
